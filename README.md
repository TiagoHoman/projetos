📌 Sobre o projeto


Calculadora de Consumo de Energia é um programa simples que calcula o consumo mensal de energia elétrica de um aparelho doméstico, com base na sua potência (em watts) e no tempo médio de uso diário (em horas).


O objetivo é ajudar a entender melhor o consumo energético dos eletrodomésticos do dia a dia. 💡


🐍 Linguagem


Desenvolvido em Python 3.


🧮 Fórmula utilizada


O consumo mensal é calculado em kWh (quilowatt-hora), considerando um mês de 30 dias:


consumoMensal = (potencia * horasDia * 30) / 1000
Variável    Descrição   Unidade
potencia    Potência do aparelho    Watts (W)
horasDia    Tempo médio de uso diário   Horas (h)
consumoMensal   Consumo total estimado no mês   kWh
▶️ Como executar
Informe os dados solicitados: nome do aparelho, potência (W) e uso diário (h).
